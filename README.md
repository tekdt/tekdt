## About

I'm an independent developer from Vietnam with a background in technical quality management and hands-on hardware service environments.

I build practical software around real operational problems, especially system deployment, network boot, diagnostics, and workflow automation.

I enjoy turning real-world technical challenges into practical and reliable solutions. My work is driven by curiosity, thoughtful engineering, and a commitment to building products that are useful, dependable, and built to last.

## How I Work

- **Problem-first:** start from the actual workflow and constraints, not from a favorite technology.
- **Reliability over demos:** test real behavior, edge cases, and failure modes, not just the happy path.
- **Practical engineering:** balance capability, usability, maintainability, and the realities of the target environment.
- **Responsible delivery:** communicate limitations and dependencies clearly, especially when a project relies on external services.
